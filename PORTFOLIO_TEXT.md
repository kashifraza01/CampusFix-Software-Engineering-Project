## LinkedIn Post
I’m excited to share **CampusFix — Smart Campus Complaint & Maintenance Tracker**, a Software Engineering semester project developed with my team.

CampusFix addresses a common campus problem: maintenance issues are often reported through informal channels, making them difficult to track from submission to resolution. We designed a structured desktop system where students/staff can submit and monitor complaints, while administrators can search, filter, assign, prioritize, and update requests through a dedicated dashboard.

**Tech stack:** Python, Tkinter/ttk, SQLite, and unittest.

**Key features:**
- Role-based authentication for users and administrators
- Complaint submission with category, location, priority, and description
- User complaint tracking
- Admin search, filtering, assignment, status updates, and notes
- Dashboard statistics for total, open, resolved, and urgent complaints
- SQLite data persistence
- Automated database tests
- Complete SRS, project report, presentation, UML diagrams, and ERD

The project follows an **Iterative and Incremental SDLC model**, allowing us to build and validate the system module by module before final integration.

My main contributions included **GUI design, requirements analysis, and final integration**.
